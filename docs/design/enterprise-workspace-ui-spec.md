# RunbookIQ 企业工作台界面规范

## 1. 视觉主张

这是一个安静、可信、适合长时间工作的企业知识工作台，而不是营销落地页或监控大屏。界面以温和白色和浅灰工作面为基础，使用一项企业品牌色表达当前空间归属；内容、证据和操作层级比装饰更重要。

品牌识别来自三个稳定元素：企业标识、企业显示名称、品牌主色。RunbookIQ 作为产品提供方保留低调署名，但不与企业品牌争夺视觉焦点。

## 2. 内容计划

### 登录与注册

- 左侧解释统一入口、企业隔离和证据问答价值。
- 右侧只保留完成认证所需字段。
- 注册字段为企业名称、管理员邮箱、密码，不出现域名或技术 slug。
- 邀请接受状态清晰展示企业、邮箱和角色。

### 应用框架

- 左侧固定导航：企业身份、六个核心模块、当前账号。
- 顶部栏：当前页面、当前知识库、服务状态和退出。
- 主内容区最大宽度受控，避免宽屏上信息散开。

### 知识问答

- 页面首屏直接呈现问题输入框和知识库范围。
- 结果区以答案为主，证据检查器在右侧。
- 评测和执行链路作为次级信息，避免挤占主要阅读任务。

### 企业设置

- 第一部分是可编辑品牌配置和实时预览。
- 第二部分是只读服务器运行配置。
- 明确角色权限与保存状态。

## 3. 交互主张

交互应快速、克制、可预测：

1. 导航切换使用 160–200ms 的背景、颜色和位移动画，帮助用户确认位置变化。
2. 页面内容进入使用一次轻微淡入和上移，不使用循环动画。
3. 品牌主色编辑时实时更新预览；只有点击保存后才持久化。
4. 所有异步操作在按钮原位置呈现进行中状态，并阻止重复提交。
5. 删除、撤销等危险操作使用低强调红色，仅在可执行时出现。

## 4. 信息层级

- 页面标题：32–38px，短句，说明当前工作任务。
- 模块标题：18–22px。
- 正文和表单：15–16px。
- 辅助文字：不低于 14px。
- 表格与代码标识允许 13–14px，但必须保持足够对比度。

## 5. 布局

- 桌面端侧栏 252px，顶部栏 72px。
- 主内容最大宽度 1440px，水平内边距 32–48px。
- 问答页在 1180px 以上使用约 2:1 双栏；以下自动单栏。
- 卡片只用于需要形成操作或阅读边界的内容；统计信息优先使用横向摘要行和分隔线。
- 移动端侧栏变为顶部横向导航，不遮挡内容。

## 6. 色彩与无障碍

- 固定正文色：接近黑色的中性绿灰。
- 固定背景：白色与低对比浅灰。
- 企业主色：仅用于主按钮、选中态、焦点环和关键状态。
- 表单、按钮和链接必须拥有键盘焦点样式。
- 状态不能只依赖颜色，需同时提供文本或图标。
